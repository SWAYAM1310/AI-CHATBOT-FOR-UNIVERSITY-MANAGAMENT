# UniAssist synthetic dataset

Generated by `scripts/generate_synthetic_data.py`  --sample (seed 42, deterministic).

- Terms: `2026-27-ODD` (in progress, as-of 2026-08-27) and `2025-26-EVEN` (completed, with results).
- Names are Gujarati-origin; student home towns are Gujarat-weighted.

## Login

Every row in `users.csv` shares the dev password **`uniassist`** (`password_hash` = PBKDF2-SHA256, 100k iterations, static salt).
Log in with any `university_email` from `students.csv` / `faculty.csv` / `admins.csv`.
